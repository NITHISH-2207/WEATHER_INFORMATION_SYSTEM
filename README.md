# 🌦️ Weather Information Management System (Java AWT + MySQL)

This project is a **Java AWT-based Weather Information Management System** that allows users to perform **CRUD operations** (Create, Read, Update, Delete) on weather data stored in a **MySQL database**.  
The system provides an intuitive GUI to manage temperature, humidity, wind speed, and weather conditions for various cities.

---

## 🚀 Features

- Add new weather records
- View weather information by city
- Update existing weather data
- Delete weather records
- Display all stored weather details
- Java AWT GUI for easy interaction
- MySQL backend for reliable data storage

---

## 🛠️ Technologies Used

| Technology | Purpose |
|-----------|--------|
| Java (AWT) | GUI Development |
| MySQL | Database |
| JDBC | Database Connectivity |

---

## 📌 Requirements

- Java JDK 8 or above
- MySQL Server
- JDBC Connector for MySQL
- Any Java IDE (Eclipse / IntelliJ / NetBeans / VS Code)
